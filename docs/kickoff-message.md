Коллеги, добрый день!

Стартуем месячную практику по проекту **OrderStation** — backend для учёта заказов (заказчики, заказы, запчасти, типовые BOM, закупка, сроки). Отдельного сайта нет: работаем через **REST API** и **Swagger**.

**Репозиторий:** https://github.com/ledozeur/OrderStation  
**Ветка по умолчанию:** `main`

### Первый день (сегодня–завтра)

1. Установить **Python 3.12+** и **Git** (Docker не обязателен на старте).
2. Клонировать репо и открыть **README** → раздел **«Кто что делает»** — там ваши зоны ответственности.
3. Пройти **docs/onboarding.md** (шаги 1–7): venv, `pytest`, запуск сервера, `/docs`, логин.
4. В GitHub взять в работу issues из milestone **W0** и **W1** с вашим лейблом (`kirill` / `andrey`).
5. Написать в issue **J-00** комментарий: «Окружение поднял, pytest зелёный» (можно скрин Swagger).

**Демо-логин в Swagger:** `admin@example.com` / `admin` (в Authorize поле **username** = email).

### Кто за что отвечает

- **Кирилл** — заказчики, заказы, отчёты по срокам (`customers`, `orders`, `reports`).
- **Андрей** — запчасти, BOM, статусы закупки (`parts`, `bom_templates`, procurement).
- Чужие файлы без issue не меняем. PR ревьюим друг у друга, потом смотрит наставник.
